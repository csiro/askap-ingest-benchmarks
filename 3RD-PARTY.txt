LICENCE COMPATIBILITY NOTES
===============================================================================

These binaries link against GPL v3 components (lofar-common, lofar-blob,
GSL, WCSlib) and ZeroC Ice 3.7, which is confirmed GPL v2 only. This
creates a theoretical incompatibility: GPL v2 copyleft requires the combined
work be distributable under GPL v2 only; GPL v3 requirements constitute
"further restrictions" from GPL v2's perspective and vice versa.

In practice:
  - This incompatibility is ubiquitous across the open source ecosystem.
  - No enforcement action based solely on GPL v2/v3 incompatibility is
    known to have been brought.
  - The primary enforced GPL obligation — providing source code or a written
    offer — is satisfied by the SOURCE CODE OFFER above.
  - CSIRO-authored code is released under GPL v2 or later, maximising
    compatibility across the dependency chain.
